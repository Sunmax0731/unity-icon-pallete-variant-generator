# リリースノート - v1.0.3

## 概要

`Unity Icon Palette Variant Generator` の v1.0.3 リリースです。

このリリースでは、Preview 操作、パレット色の個別制御、解析プリセット、差分プレビュー、エクスポート前チェック、境界トリム、パラメータ tooltip を中心に、日常的な色替え作業の操作性を改善しました。

## 主な変更

- Preview 上のクリックでパレット色を選択できるようにしました。
- Preview はクリックで色選択、ドラッグで表示位置移動ができるようにしました。
- Preview に `BrushSelect` モードを追加し、複数色をドラッグ選択して個別ルールを作成できるようにしました。
- 選択した色を `Visible in Export` で ON/OFF できるようにしました。OFF の色は書き出し時に alpha 0 として扱われます。
- 選択中の色またはグループを Preview 上でハイライト表示できるようにしました。
- パレット色のルール状態バッジ、選択色情報、効果ハイライトを追加しました。
- Analyze セクションにカテゴリプリセットを追加しました。
- 設定セクションの折りたたみ、Preview ミニツールバー、Undo/Redo を追加しました。
- Difference Preview、Export 前チェック、Boundary Trim クリーンアップを追加しました。
- 解析、グループ、ノイズ削除、エッジ外側クリーンアップの各パラメータに、現在の言語設定に応じた tooltip 説明を追加しました。
- Unity 6 の非推奨警告に対応し、`GetInstanceID()` を使わないようにしました。

## 既知の制限

- SpriteAtlas の直接編集は対象外です。
- エッジ外側クリーンアップは、小さな分離領域を対象にします。主要領域と接続した外側の縁取りを削る処理は今後の改善対象です。
