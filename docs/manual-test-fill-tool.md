# 塗りつぶしツール 手動確認

## 目的

塗りつぶしツールが、クリックしたピクセルと同じ RGBA の隣接領域だけを一括で塗りつぶすことを確認する。

## 共通準備

1. Unity `6000.4.0f1` でプロジェクトを開く。
2. `Tools > Palette Variant Generator > メイン画面` を開く。
3. JPEG または PNG を `Source Image` に設定する。
4. `Analyze`、`Auto Group`、`Preview` を実行する。
5. `Preview Mode` を `描画` にする。
6. `ツール設定 > ツール` を `塗りつぶし` にする。
7. `描画色` と `描画不透明度` を確認し、分かりやすい色に設定する。

## TC-FILL-01 読み込み画像を塗りつぶす

1. `編集対象` を `読み込み画像` にする。
2. Preview 上で、同じ色が連続している背景や模様の一部をクリックする。

期待結果:

- クリックしたピクセルと RGBA が完全一致し、上下左右でつながっている領域だけが塗りつぶされる。
- 別色の境界を越えて塗りつぶされない。
- 斜めに接しているだけの同色ピクセルは、上下左右でつながっていなければ塗りつぶされない。
- JPEG 読み込み画像でも内部 PNG バッファ上で結果が保持される。

## TC-FILL-02 透明領域を塗りつぶす

1. `編集対象` を `読み込み画像` にする。
2. 消しゴムで透明領域を作る。
3. `ツール` を `塗りつぶし` に戻す。
4. 透明領域の一部をクリックする。

期待結果:

- 透明ピクセル同士で上下左右につながっている領域が塗りつぶされる。
- 不透明ピクセルの領域には広がらない。

## TC-FILL-03 描画レイヤーを塗りつぶす

1. `描画レイヤー追加` で Paint Layer を作る。
2. `編集対象` を `アクティブレイヤー` にする。
3. ブラシで同じ色の領域を描く。
4. `ツール` を `塗りつぶし` にして、その領域をクリックする。

期待結果:

- アクティブレイヤー上の連結領域だけが塗りつぶされる。
- 下の読み込み画像は変更されない。
- レイヤーがロック中の場合は編集されない。

## TC-FILL-04 Export

1. 塗りつぶし結果を含む状態で `Preview` を更新する。
2. `Export` を実行する。
3. 出力 PNG を確認する。

期待結果:

- Preview と同じ塗りつぶし結果が PNG に反映される。
- 透明を含む場合、PNG の alpha が保持される。
- `Assets/` 配下に出力した場合、`Alpha Is Transparency` が ON になる。
