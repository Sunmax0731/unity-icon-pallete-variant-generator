## 既知の制限

- SpriteAtlas の直接編集は対象外。
- `Alpha Is Transparency` 自動設定は `Assets/` 配下に出力した PNG のみ対象。
- 読み込み画像への直接編集は元ファイルではなく Session JSON / Export PNG に保持される。
