# Unity Icon Palette Variant Generator 要件定義書

## 1. 目的

本エディタ拡張は、Unity プロジェクト内の画像アセットを読み込み、画像に含まれる色を自動解析してカラーパレットを生成し、近傍色をグルーピングした上で、グループ単位またはカラーコード単位の色変換を行うためのツールである。

主な目的は、単一のアイテムアイコンから複数の色違いパターンを効率よく作成することにある。

例:

- 鉱石アイコンの色違い作成
- 薬草アイコンのランク違い作成
- 宝石アイコンの属性違い作成
- 装備アイコンの素材違い作成
- UI アイコンのテーマカラー違い作成

## 2. 想定利用形態

- Unity Editor 上で動作するエディタ拡張として提供する。
- 対象は Unity プロジェクト内の画像アセットとする。
- 元画像は破壊せず、変換結果を別ファイルとして出力する。
- 変換設定はセッション JSON / プリセット JSON として保存できるようにする。
- BOOTH 等で配布する場合は、GitHub Release に含める成果物として `unitypackage` または UPM 形式のパッケージを想定する。

## 3. 対象ユーザー

### 3.1 主対象

- Unity で RPG / MMORPG / 2D ゲーム / UI ツールを開発している個人開発者
- アイテムアイコンや素材画像を多数扱う開発者
- 色違いアセットを手作業で作る負担を減らしたい開発者

### 3.2 副対象

- BOOTH 等でアイコン素材を制作・販売するクリエイター
- ゲーム内素材のランク違い・属性違いを大量に作成する人
- 画像編集ソフトを使わず Unity 内で簡易的な色替えを行いたい人

## 4. スコープ

### 4.1 対象範囲

- Unity プロジェクト内画像の選択
- 画像ピクセルからの色抽出
- 透明ピクセルを除外した色解析
- 近傍色の自動グルーピング
- 任意グループ数によるパレット集約
- グループ単位の色置換
- カラーコード単位の色置換
- 置換比率によるブレンド変換
- 変換前後プレビュー
- PNG 出力
- セッション / プリセット保存
- バリデーションと警告表示

### 4.2 対象外

初期版では以下を対象外とする。

- Photoshop や Aseprite のような高度なレイヤー編集
- ブラシ編集、手描き修正
- AI による画像生成
- 複数画像の高度な一括解析
- SpriteAtlas の直接編集
- 元画像アセットの直接上書き
- ランタイム動作

ただし、将来的な拡張として一括処理や SpriteAtlas 連携は検討可能とする。

## 5. 機能要件

## 5.1 画像読み込み

| ID | 要件 | 優先度 |
|---|---|---|
| FR-001 | Unity プロジェクト内の Texture2D / PNG 画像を選択できる。 | 必須 |
| FR-002 | 選択画像のプレビューを表示できる。 | 必須 |
| FR-003 | 画像サイズ、アセットパス、アルファ有無を表示できる。 | 必須 |
| FR-004 | 読み込み不可画像、巨大画像、非対応形式に警告を出す。 | 必須 |

### 補足

`Texture2D.GetPixels32()` が使えない場合でも、AssetDatabase からファイル実体を読み込み `ImageConversion.LoadImage()` で解析用 Texture2D を生成する方針とする。

| FR-103 | 完全一致カラーの一覧を表示できる。 | 必須 |

### 推奨する色距離

初期実装では以下の方針とする。

- 内部処理: RGB または HSV ベースでも実装可能
- 推奨処理: CIE Lab 変換後の色距離を利用
- MVP: RGB 距離 + 量子化で実装し、後から Lab 対応でも可

## 5.5 色変更ルール

| ID | 要件 | 優先度 |
|---|---|---|
| FR-401 | グループ単位で置換色を指定できる。 | 必須 |
| FR-402 | グループ単位で反映率を指定できる。 | 必須 |
| FR-403 | 個別カラーコード単位で置換色と反映率を指定できる。 | 必須 |
| FR-404 | グループ一律置換と個別カラー置換を切り替えられる。 | 必須 |
| FR-405 | アルファ値を維持するか変更するか選択できる。 | 推奨 |
| FR-406 | 明度・彩度を維持した色相寄せモードを利用できる。 | 将来 |

### 反映率の考え方

反映率は 0.0 ～ 1.0 とする。

```text
0.0 = 元色を維持
1.0 = 置換色に完全変換
0.5 = 元色と置換色を半分ずつブレンド
```

基本式:

```text
outputColor = Lerp(originalColor, targetColor, ratio)
```

## 6. 非機能要件

## 6.1 操作性

- Unity Editor に馴染む UI とする。
- 元画像、パレット、グループ、プレビュー、出力設定を 1 画面で確認できる構成とする。
- 画像編集ソフトに不慣れなユーザーでも使えるように、操作は「読み込み → 自動生成 → 調整 → プレビュー → 出力」に整理する。

## 6.2 安全性

- 元画像は直接変更しない。
- 出力時は既存ファイルへの上書き有無を明示する。
- セッション保存により、同じ条件で再生成できるようにする。

## 6.3 性能

- 64x64 ～ 512x512 程度のアイコン画像を主対象とする。
- 1024x1024 を超える画像は警告を表示する。
- 色抽出・プレビュー更新は Editor の操作を阻害しない速度を目指す。
- プレビュー更新は必要に応じて手動更新またはデバウンスを行う。

## 6.4 保守性

- 画像解析、グルーピング、色変換、入出力をサービスクラスに分離する。
- EditorWindow に処理を集中させない。
- 将来的な一括処理、SpriteAtlas 連携、色距離アルゴリズム差し替えに備える。

## 7. 受け入れ基準

### MVP 完了条件

- Unity プロジェクト内の PNG を選択できる。
- 画像から色を抽出し、パレット一覧を表示できる。
- 任意のグループ数で近傍色をグループ化できる。
- グループごとに置換色と反映率を設定できる。
- 変換結果をプレビューできる。
- PNG として別ファイルに出力できる。
- 設定を JSON に保存し、再読み込みできる。
- 元画像は変更されない。

### 品質確認条件

- 透過ピクセルが意図せず塗られない。
- アルファ値を維持した出力ができる。
- 同じ設定を再適用したとき、同じ結果が出力される。
- 色数の多いアンチエイリアス画像でも、近い色が過度にばらけない。
- 出力画像が Unity の AssetDatabase に反映される。
