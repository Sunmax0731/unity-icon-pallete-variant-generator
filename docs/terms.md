## 注意事項

- 本ツールは Unity Editor 拡張です。ランタイム機能は含みません。
- 元画像ファイルは直接上書きしませんが、作業前にプロジェクトのバックアップを推奨します。
- JPEG は内部で RGBA バッファへ変換して編集します。透明化結果を保持するには PNG として Export してください。
- 出力 PNG の `Alpha Is Transparency` 自動設定は Unity Project の `Assets/` 配下に出力した場合のみ適用されます。
